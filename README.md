# DevLinks

Página de links pessoais (estilo "linktree"), desenvolvida durante o curso da Rocketseat.

## Funcionalidades

- Alternância entre tema claro e escuro
- Lista de links personalizados
- Ícones de redes sociais
- Layout responsivo

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador (recomendado usar a extensão Live Server no VS Code)
